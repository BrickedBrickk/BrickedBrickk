### What I work on

- **GPU compute & weird hardware** — OpenCL kernels, mining stacks, odd accelerators
- **Emulation, porting & RE** — making native code and protocols fit foreign runtimes
- **Browser networking** — WebRTC, WebSockets, hand-rolled binary protocols
- **Low-level systems & AI inference** — kernels, tooling, performance work

---

### Featured

**[Pearl-BC160](https://github.com/BrickedBrickk/Pearl-BC160)** — Pearl (PRL) GPU miner for the AMD BC-160: Rust + OpenCL port of a proof-of-useful-work pipeline that officially has no AMD backend.

**[QelloxHashV1](https://github.com/BrickedBrickk/QelloxHashV1)** — Consumer-GPU proof-of-work algorithm with a 32-lane integer VM, formal spec, CPU reference, and WGSL backend.

**[Eagler-Relay-Client](https://github.com/BrickedBrickk/Eagler-Relay-Client)** — Dependency-free browser client for the Eaglercraft relay protocol: binary codec + WebRTC host/join in TypeScript.
